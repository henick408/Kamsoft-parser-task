# Content Parser API

ASP.NET Core Web API (.NET 9) umożliwiające dekodowanie danych Base64 oraz parsowanie zawartości w formatach CSV i INTERNAL_JSON.

## Wymagania

- .NET 9 SDK

Sprawdzenie zainstalowanej wersji:

    dotnet --version

## Uruchomienie aplikacji lokalnie

1. Należy sklonować repozytorium:

    git clone **https://github.com/henick408/kamsoft-parser-task**

2. Przejść do katalogu projektu:

    cd **kamsoft-parser-task**

3. Uruchomić aplikację:

    dotnet run

Po uruchomieniu aplikacja będzie dostępna pod adresem **http://localhost:5000**

Swagger UI będzie dostępne pod adresem **http://localhost:5000/swagger**
